## 📝 Pull Request 컨벤션

우리 팀의 원활한 코드 리뷰와 히스토리 관리를 위해 아래 규칙을 준수해 주세요!

### 🎯 PR 제목 규칙
제목은 **`[태그] 요약 내용 (#이슈번호)`** 형태로 작성합니다.

| 태그 (Tag) | 설명 (Description) | 예시 (Example) |
| :--- | :--- | :--- |
| **`Feat`** | 새로운 기능 추가 | `[Feat] 로그인 API 및 세션 처리 구현 (#12)` |
| **`Fix`** | 버그 및 에러 수정 | `[Fix] JSP 페이지 한글 깨짐 인코딩 오류 수정 (#15)` |
| **`Docs`** | 문서 수정 (README, 주석 등) | `[Docs] README 파일에 PR 컨벤션 가이드 추가` |
| **`Style`** | 코드 포맷팅, 세미콜론 누락 (로직 변경 X) | `[Style] 1teamSprint 소스 코드 인덴트 정렬` |
| **`Refactor`**| 코드 리팩토링 (구조 개선) | `[Refactor] MemberDAO 데이터베이스 연결 로직 최적화` |
| **`Test`** | 테스트 코드 추가 및 수정 | `[Test] 회원가입 유효성 검사 단위 테스트 추가` |
| **`Chore`** | 빌드 설정, 라이브러리 추가, 단순 수정 | `[Chore] pom.xml에 톰캣 서블릿 라이브러리 추가` |
